只记一条：屏/模块丝印写什么，就在开发板上找对应的 G 数字。
  1. 别看 Wokwi 排针上下顺序——和你真机不一样，GPIO 号才对得上。
  2. 板子 天线在上、USB 在下，看两侧排针丝印（G1、G11…）。
  3. 屏和麦只接 3V3，不要接 V5IN / 5V。
别踩坑：右侧 TX0 / RX0 是 USB 下载口（GPIO43/44），不是 4G。 4G 用左侧 G17、G18。EN = 复位键（= Wokwi 的 RST）。

★只接屏幕 + ESP32 + 电源键能玩什么？

你现在就是这个状态！已经能跑起来一个"电子宠物"了。

✓ 能用的功能：
  • 屏幕亮起来 — 显示一个会眨眼、挥手、蹦跳的小人脸
  • 时钟显示 — 左上角有时钟（从开机开始计时）
  • 电源键控制：
    • 单击 → 开关屏幕
    • 双击 → 切换 DND 免打扰模式
    • 长按 → 开关屏幕
  • 触摸交互：
    • 屏幕关时点一下 → 亮屏
    • 空闲时点一下 → 触发"聆听"动画（但没麦，只是视觉效果）
    • 说话动画时点一下 → 打断回到空闲
  • 串口命令（USB 连着电脑就能用）：
    • a → 触发闹钟动画
    • n / o → WiFi 开/关
    • 4 → 切换 4G 状态
    • r → 横竖屏旋转
    • h → 显示所有命令
✗ 还不能用的功能：
  • 语音对话（需要麦克风 + 喇叭）
  • AI 回复（需要 4G 模块联网）
  • 对讲键（还没接）

结论：先享受你的电子宠物吧！它会眨眼、挥手、蹦跳，你可以点它玩。等杜邦线到了再接其他的。
